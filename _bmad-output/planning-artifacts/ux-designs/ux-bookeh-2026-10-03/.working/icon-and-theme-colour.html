App icon and theme colour

Story 1.21 needs both before the manifest can be written. Tap an icon to see it on a home screen. The grid shows three marks on three grounds.

Icon

  • A, underline. A light lowercase b on the coral line that marks a link or the primary button.
  • B, selection bar. The same b with the coral bar that marks the open row.
  • C, shelf. Three spines drawn as lines on a shelf, one of them coral. No lettering.

Ground 3, coral, breaks the no-fills rule. It's here because the home screen sits outside the interface and coral stands out among other icons.

On the phone

Picked: A1

Theme colour

This colour tints the system bar on Android, Safari's address bar, and the window title on desktop. On an iPhone the installed app shows the page's own ground under the clock, so there the choice hardly shows.

How it would be built: the theme is a cookie read on the server (story 1.18), so the layout can emit the matching theme-color for light or dark, and a light/dark pair with media when the theme follows the system. The manifest takes one theme_color and one background_color (the Android splash screen behind the icon). Both would be the light values.
