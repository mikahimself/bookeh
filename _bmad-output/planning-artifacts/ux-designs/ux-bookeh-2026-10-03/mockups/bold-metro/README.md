# Bold Metro canvas

Picked by Mika on 2026-11-10 over three rounds. Recorded in `../../../../sprint-change-proposal-2026-11-10.md` and built by Epic 11.

- Live canvas: https://claude.ai/artifact/W62ePXuepskzXzJ17HhsCE (private to Mika).
- These files are its sources at the time of the pick. They are Design-canvas artboards (`.dc.html`) and need the canvas runtime (`support.js`) to render, so open the live canvas to view them. Read them here for exact values.

| File | Shows |
|---|---|
| `Main.dc.html` | Collection, covers, light: 56px headings, the s / m / l switch then the rows / covers Icon switch, Currently reading, the App bar (add book, filter, select). |
| `CollectionRows.dc.html` | The same in rows, dark. |
| `Detail.dc.html` | Book detail as the sheet: the header with the Rating, the reading Segmented control, the Folding sections, Add to wishlist, and the App bar (edit, lend, move, remove, ⋯). Interactive. |
| `Stats.dc.html` | Stats tiles with the shared number size (its Tweaks change the pages and spent figures), By month, Nerdy stats. |
| `Scan.dc.html` | Add book: the corner target, the ISBN field, the App bar (torch, add without ISBN, find by title / author). |
| `Choices.dc.html` | The options compared, with the picks marked. |

DESIGN.md and EXPERIENCE.md win on any conflict with these files. The data in them (titles, numbers, dates) is sample content.
