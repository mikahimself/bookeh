**P1. The unit lane was red on three pushes (9.6, 9.10, 9.21) and went green only incidentally in 9.22.**

- Source: CI runs `41980800427` (9.6), `42002694544` (9.10), `42029739265` (9.21), all failing at "Run npm run test:unit". The failures include `TypeError: Cannot read properties of undefined (reading 'tags')` in `bookDetailCopyLine`, `collectionSelection` and `loansPage`. The fix sits in `d0025ff` (9.22), which touched that helper plus `collectionSelection`, `loansPage` and `unavailableActions` unit specs while delivering a different feature. The next green push is `42036651691` (9.22).

- **Instance: accept (fixed).** Per the recorded policy "CI: owner watches", there is no CI gate on done. **Prevention:** run `npm run test:unit` before the commit of any story that changes a type consumed by `tests/helpers/*`; that is a story-completion habit, not a new test. Action 1.
