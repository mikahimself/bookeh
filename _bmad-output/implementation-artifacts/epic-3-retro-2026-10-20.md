### Diff-scope review (bmad-review: adversarial, edge-case-hunter, verification-gap)

- **R1. The edition the user confirmed is not the edition the save builds (adversarial 1, 2; edge 2, 4, 13, 14; *confirmed*).** `pick` is a bare index into whatever `lookupSources()` returns at save time.
